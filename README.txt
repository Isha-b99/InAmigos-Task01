InAmigos Foundation — Image Guide
==================================

WHERE THE CURRENT PHOTOS COME FROM
-----------------------------------
The page now shows real photographs in the hero, About, and all six project
cards. These are free-to-use stock photos from Pexels (hotlinked directly
from images.pexels.com — no attribution required under the Pexels License,
https://www.pexels.com/license/). They are NOT official InAmigos photos:
real photographs from InAmigos' Instagram/Facebook are copyrighted by the
foundation, so they were not pulled into this third-party project without
permission.

Because the images are hotlinked, an internet connection is needed to see
them when you open index.html. If you'd rather self-host, download each
photo from its Pexels page and save it locally using the filenames below,
then update the matching <img src="..."> in index.html to point at your
local file instead of the pexels.com URL.

SWAPPING IN OFFICIAL PHOTOS LATER
-----------------------------------
If you get permission to use official InAmigos photos, drop them into this
folder using the filenames below and update the matching <img src="..."> in
index.html.

Suggested filenames and where each is used:

  hero-community.jpg       -> Hero section, replaces .hero-illustration
  about-team.jpg           -> About section, replaces .about-illustration
  project-seva.jpg         -> Project Seva card
  project-bachpanshala.jpg -> Project Bachpanshala card
  project-jeev.jpg         -> Project Jeev card
  project-udaan.jpg        -> Project Udaan card
  project-prakriti.jpg     -> Project Prakriti card
  project-vikas.jpg        -> Project Vikas card
  event-world-water-day.jpg          -> Highlights: World Water Day 2025
  event-happiness-day.jpg            -> Highlights: International Day of Happiness 2025
  event-women-girls-science.jpg      -> Highlights: Women & Girls in Science Day 2025

Recommended image specs:
  - Hero / about images: 1600x1200px minimum, landscape, JPG or WebP
  - Project card images: 800x600px, landscape, JPG or WebP
  - Keep file sizes under ~300KB each (compress with squoosh.app or similar)
  - Always credit "Image: InAmigos Foundation" in a caption if required by
    the foundation's usage terms.
